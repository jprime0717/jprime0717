## 📌 Proyectos destacados / Featured projects

### 🌊 Fluvio — Diagnóstico de Ciberseguridad
Aplicación para **evaluar la madurez en ciberseguridad** de una organización. Motor de scoring sobre **34 controles en 8 dominios ponderados**, escala 0–5, alineado a **NIST CSF 2.0, ISO/IEC 27001:2022, MSPI (MinTIC) y Ley 1581 de 2012**. Calcula la madurez global, clasifica hallazgos por nivel de riesgo (crítico / alto / medio) y genera el panorama para el informe al cliente. Construida con Claude Code.

`Cybersecurity maturity assessment app — 34 controls · 8 weighted domains · 0–5 scale · NIST CSF 2.0 / ISO 27001 aligned.`
